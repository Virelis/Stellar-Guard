# Institutional Glossary of Terms & Standards

### CAP-0077
**Core Advancement Proposal 0077:** A Stellar protocol proposal enabling targeted asset quarantine on individual trustlines without disrupting innocent third-party liquidity.

### Clawback
A native Stellar ledger feature allowing regulated asset issuers to revoke and repossess balances from authorized accounts in compliance with legal or statutory obligations.

### Ed25519
The Edwards-curve Digital Signature Algorithm utilized across the Stellar network for account keys, transaction authentication, and multisig governance.

### FATF Recommendation 16 (Travel Rule)
The Financial Action Task Force standard requiring financial institutions and VASPs to share originator and beneficiary customer data alongside high-value cryptocurrency transfers.

### Horizon
The REST API server that enables applications to stream ledger events, submit transactions, and inspect account states on the Stellar network.

### Quorum
The minimum number of affirmative cryptographic signatures required from authorized administrative trustees before a governance action can execute on-chain.

### SEP-0001
The Stellar Ecosystem Proposal defining the `stellar.toml` metadata format published at an organization's domain `.well-known/stellar.toml`.

### SEP-0008
The Stellar Ecosystem Proposal specifying regulated assets and automated transaction approval criteria.

### SEP-0010
The Stellar Ecosystem Proposal defining mutual cryptographic web authentication (Stellar WebAuth) using Ed25519 challenge transactions.

### Soroban
The native Rust-based smart contract platform for the Stellar network, featuring deterministic execution, WASM bytecode, and bounded storage rent.

### StrKey
The string encoding standard used by Stellar to represent public keys (starting with `G`), contract IDs (starting with `C`), and secret keys (starting with `S`).

### XDR
**External Data Representation:** The binary serialization standard used across Stellar Core to encode transactions, ledgers, and operations.
